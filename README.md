# bursen

bursen is a terminal planner for Old School RuneScape Grand Exchange flipping.

This repository hosts bursen's releases. Download a build from
[Releases](https://github.com/pxjx22/bursen-releases/releases).

No release has been published yet.

## Install

Once a release is out, install the latest one on Linux or macOS with:

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/pxjx22/bursen-releases/releases/latest/download/bursen-installer.sh | sh
```

Or download the archive for your platform from the release page and put the
`bursen` binary on your `PATH`. Each release has `sha256.sum` for checking
downloads. Windows is not supported yet.
